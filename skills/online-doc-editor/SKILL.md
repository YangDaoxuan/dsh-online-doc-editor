# 在线文档编辑

完成当前用户授权范围内的在线编辑。用户要求先讨论时先读再给方案；已有授权时自主推进。根据文档与对话确定受众、章节边界、参照章节、可改内容、修订要求，不重复询问已明确的信息。未知样式优先参照同文档的同级段落。

按任务加载参考：涉及写作或润色时读 [writing.md](references/writing.md)；涉及标题、编号或版式时读 [formatting.md](references/formatting.md)；用浏览器操作金山文档时读 [kdocs.md](references/kdocs.md)。需要了解依据时再读 [sources.md](references/sources.md)。

先确认当前工具及其实际能力，复用任务对应的页面。已登录、可读和可编辑分别确认。读取目标正文与前后文；工具栏、目录、页面数或空的采集结果不能代替正文。正文或关键格式无法取得时说明限制，不猜测已读内容。

普通小改直接完成；较长任务先形成简短修改清单：目标锚点、预期旧文本、拟改内容／格式、保留项与核验方式。先检查计划与当前原文相符，再写入。使用专用文档工具时按其真实 schema 调用；没有时使用已存在的浏览器能力。不得把设计中的工具名或未知 API 当成已安装能力。

操作前确认目标文档、章节、实际焦点与选区。默认逐自然段处理、标题独立处理；经验证能保留段落、格式和修订后，可适度合批。先完成一个代表性段落，证明当前方法有效。页面重排、导航、协作者变动或手动接管后，重新读取状态与原文。

每批修改后核对实际文字、前后段落边界和要求保留的结构；格式操作同时回读能取得的设置与视觉效果。修订按用户要求保持，不擅自接受、拒绝或关闭。字数变化、工具返回成功或页面显示改变只能辅助判断，保存状态单独核验。

超时或中断后先核对结果，避免重复写入。选区不符就停止当前写入、重新定位；不要在未知位置连续删除或撤销。仅在可确认不会影响协作者新修改时恢复本次动作。当前方法失败且没有新的依据时换方法或明确能力缺口，继续仍可独立完成的工作。

跨多段或跨会话时，在工作区记录最少量的任务检查点：文档、范围、样式参照、已验证项、下一锚点和待确认状态。恢复后核对在线现状，不直接重放旧写入。

交付时简要说明实际改动、核验结果、保存状态及未完成项。仅改格式且文本比较通过时，说明“文字内容未改动”。没有核验的项目明确写“未核实”，不把已提交等同于已保存。
