# 金山文档与当前浏览器工具

2026-10-25 的已检查基线是 dsh-builtin-browser 0.4.15；以下不承诺新版本行为。先检查当前会话实际工具，再决定方法。本文不要求安装新的插件。

用 dsh_browser_session / dsh_browser_list_tabs 确认任务页面，用真实返回的 tabId 切换；参数不支持 shell 命令替换。通过 snapshot / a11y 定位控件，content 限定目标区域并检查截断。必要时 execute 进行小范围只读探查，不返回整页无关 HTML 或凭据。

可选浏览器增强版 0.4.15-plus.1 在旧单键接口上增加 modifiers 数组：例如 key 为 f，modifiers 为 [Control]。写入前调用 dsh_browser_state，核对 session、tabId、url、focus 和 selection；将 observationId 传给 dsh_browser_click / type / key 的 expectedObservation。观察标识单次使用，失效时重新观察。它检测页面、焦点、选区及视口尺寸变化，不是服务器文档版本或多人协作锁。

在已加载 docedit.4 时，dsh_browser_state 可传 includeDocumentView=true，同时取得有数量上限的渲染文本行、大纲可见项和当前可见样式控件，优先用于局部读取，减少临时脚本。lines 是坐标分组的渲染行，不是段落；completeDocument=false。intersectsViewport=false 的坐标不可直接点击；outline.centerHit=false 提醒中心点被遮挡或裁剪。available=false 时说明当前页面结构不受支持，不能当空正文。该视图不确认云端保存或修订记录。docedit.3 的 centerHit 曾错误接受 BODY 等祖先命中，已在 .4 修正；旧版不依赖该字段。

dsh_browser_drag 接受 fromX/fromY/toX/toY 和必填 expectedObservation，坐标为当前视口 CSS 像素。拖选后重新读取状态与实际选区。state 中 documentModelVerified=false 表示浏览器读数不能单独证明 WPS 正文选区。只有运行时已出现这些工具时才使用增强能力；旧版依然以单键和可见菜单为限。

dsh_browser_type 在当前焦点插入文字；输入前确认它是目标正文。set_value / fill 适用于普通控件，不可将整个在线文档根节点当表单清空重写。直接改 DOM 的 innerHTML 或 CSS 不证明修改进入文档模型并保存。

页面可能只渲染可见部分；DOM、可访问文本、canvas 和代理输入框可能并存。window.getSelection、隐藏输入框的 value、页面状态栏和截图均不能单独证明文档真实选区。当前方法采集结果持续为空时判定方法失效，不把空结果当全文。

大纲未列出子项，先检查折叠和标题样式；不能直接断定正文缺少标题。文本层合并空白后的连续字符串，也不能证明原稿没有段落。补标题、拆段或改级别前，核对实际页面与相邻标题。

在标题末按 Enter 新建正文时，可能继承大纲级别，即使页面上存在“正文”字样也不能据此判定成功。检查当前可见样式控件、新段是否误入大纲及前后段落；需要时在新段套用正文样式。CSS 字号受页面缩放影响，不可把 16px 直接认定为“小四”；具体字号以编辑器可见控件或段落设置为准。读取按钮状态时先对完整 class/aria 状态判断，再截断用于显示的文本。

已测试界面的“开始 → 行距 → 其他(M)…”打开右侧段落属性窗格，可读取并单独设置“大纲级别”；它不是带“确定/取消”的模态框，选项实时生效。先确认焦点对应目标段，再操作；只改大纲级别时保留原有字体字号，回读大纲层级和相邻文字。界面版本变化时以实际可见控件为准。

长文档优先用可见大纲或唯一原句定位。大纲元素有宽高仍可能被滚动容器裁剪；必要时先将该项滚入视口，重新读取坐标，并确认点击点实际命中目标。跳转后回读章节号、标题和相邻正文。查找是子串匹配时，2.1.3 也可能命中 4.2.1.3；需检查结果计数和上下文。滚动采集出现跳段或重复且不能可靠拼接时，改用已验证锚点，不把零散文字包装为全节全文。

选择唯一原文片段，并用章节及相邻句子消除歧义。变更后复核原文／新文和段落边界，区分修订中的旧标题。无法核实选区时不做删除、替换或跨段格式操作。

WPS 桌面客户端 JSAPI、应用接入的 WebOffice SDK 与普通金山文档分享页不等价。不得因为官方有 Range、书签或查找接口，就猜测当前分享页存在可调用的 Application 对象；正式 SDK 需确认接入环境和对应接口。不要为探索私有接口反复写入原文。

截图用于布局、复杂选区及控件定位；取得截图后核对它对应当前文档视口。插件的云端视觉处理遵守现有设置，不能自行启用或改动。登录或验证码确需人工处理时说明具体阻碍。

如果当前环境另装 BrowserSkill 或专用文档适配插件，按其说明选择一个后端并保持会话归属，不能混用不同浏览器中的相似页面。尚未安装的 online_doc_* 是提案，不是可调用能力。

在可选浏览器增强版中，金山文档和 WPS 页面上的 click/type/key 必须传入观察标识；drag 在所有页面上都需要标识。普通页面保留旧调用兼容性。不能把未传标识的普通页面点击或输入描述成“标识已消费”。DOM脚本读取和截图不消费标识，但如果改变焦点或选区则需重新观察。
