# 格式与结构

以用户指定模板或同文档同级段落建立样式参照。只记录任务需要的字段：中西文字体、字号、颜色、加粗、段落样式、大纲级别、行距、缩进、段前段后和编号。无法读取的字段写未知；截图不能证明精确的磅值或字符缩进量。

每项修改明确允许改变什么、需要保留什么。复制样式时避免连带改变强调、超链接、引用、局部中英文字体和编号；混合格式的段落不能默认整体覆盖。

标题应是独立段落，并具有正确的层级和大纲语义。调整后检查标题文字、段落边界、样式、大纲位置与编号；加粗或放大不等于设置标题。自动编号用编辑器的编号功能，不以手打相同数字替代。功能不可验证时标明限制。

保留段落标记、分节、书签和其他未授权结构。文本中的换行、软回车和自然段不是同一回事；使用编辑器支持且已经验证的段落操作。正文替换后检查标题未与邻段粘连，段首段尾没有丢字和重复。

仅改格式时比较前后文字、标点、数字及引用。修订模式下区分当前文本和已删除标记，不能用简单 DOM 字符串的总长度作为判据。格式字段回读与截图检查互相补充；大纲、保存与修订需要分别验证。

结构复杂且影响分页时扩大视觉核验范围，但不为局部字体修改重复截图全文。版式改善不能作为改写内容、接受全部修订或重排全文的授权。
