# 写作与润色

先读目标节、前后节及用户指定的参照节。明确该节应回答的问题、已有结论、支撑材料和篇幅用途。沿用文档的术语、课题划分和论述层次。参照其他课题的形式时，只迁移组织方法，不迁移其技术内容或成果。

写作稿应能回答：研究什么问题、对象与约束是什么、采用什么方法、为何适用、怎样验证、输出如何服务本节目标。按实际需要取舍，不机械地让每段包含这六项。先检查逻辑和事实，再做语言润色；不为凑页数添加同义重复。

区分原文事实、来源支持的信息与拟新增的研究建议。新增论文、案例、数据或政策判断需要可核验来源；资料只支持较弱结论时保留范围和不确定性。保持引文编号及其对应关系，不能为语言流畅删掉技术条件。

用户要求自然、减少模板感时，优先明确主语、动作、因果与对象，删去没有信息增量的套话，合并不必要的小标题和碎片化列点。并列关系清晰时可以用列表，映射和比较可以用表格。正式申报书仍保持文体，不把自然表达等同于口语化，也不以检测器分数为目标。

成稿后从读者角度检查：只读本节能否知道研究对象和目的；术语是否解释并保持一致；方法是否真正回应问题；成果是否超出材料支持；与其他章节是否重复或冲突。修正具体问题后再写入。此检查可由当前 agent 完成，但不能声称做过独立盲审。

术语一致应以含义一致为前提；例如总项目的“六网”与子课题的“三网”可以各有适用范围。不要为统一措辞替换不同概念，也不要把各小节结尾强制改成同一模板句。

用户只授权格式修改时，不执行这里的重写或润色。
